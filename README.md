# Conversor de Unidades

Aplicación de Laura Armando con Vue 3, Vue Router y Vuetify. Permite convertir kilómetros a millas, Celsius a Fahrenheit, kilogramos a libras, litros a galones y metros a pies.

[Probar la demo](https://lolamora744-dev.github.io/Conversor-de-Unidades/)

## Ejecutar y compilar

```sh
npm ci
npm run dev
```

Para generar la demo de producción, ejecutá `npm run build`. Los archivos se generan en `docs`, que es la carpeta publicada con GitHub Pages.

## Código fuente

`src/App.vue` contiene la interfaz principal. Los componentes están en `src/components`. El proyecto conserva su ZIP original y también permite revisar los archivos directamente desde GitHub.

## Alcance

La navegación usa rutas con # para que las secciones se puedan abrir y recargar en GitHub Pages. Las conversiones muestran resultados con dos decimales.
